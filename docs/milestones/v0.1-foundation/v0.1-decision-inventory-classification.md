## What This Means

The correct v0.1 target is not “101 decisions completed.” The target is a compact foundation made of approximately 19 source decisions consolidated into a smaller set of canonical governance documents, plus the two release gates.

No decision should be deleted merely because it is deferred. The next cleanup step should introduce an explicit archive/deferred convention, update the decision log, and then consolidate duplicates while preserving traceability.
