## Governance Rules

1. Only assets recorded as approved in this register are canonical.
2. Draft concepts must be clearly marked as drafts.
3. Duplicate or obsolete assets must not be presented as current without an explicit version label.
4. Material changes to approved assets require controlled change documentation.
5. Later roadmap milestones must reference the canonical v0.2 assets rather than creating independent brand variants.
