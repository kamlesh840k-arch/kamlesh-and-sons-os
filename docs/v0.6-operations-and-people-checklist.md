# v0.6 Operations & People — Documentation and Activation Checklist

**Document ID:** DOC-V06-GATE-001
**Status:** Documentation complete — pilot evidence pending

## Documentation Gate

- [x] Core process and control architecture defined
- [x] SOP content/version standard defined
- [x] Inventory, cash, service, procurement, safety and exception controls defined
- [x] Roles, hiring, onboarding, training, performance and exit controls defined
- [x] Operating cadence, measures and closure evidence defined

## Activation / Real-World Gate

- [ ] Operations and People Owners appointed with authority
- [ ] Site-specific SOPs, role charters and segregation approved
- [ ] Employment, safety and operating compliance reviewed
- [ ] Staff hired/onboarded and competence observed
- [ ] Inventory, cash, service and incident controls piloted
- [ ] Exceptions and corrective actions resolved
- [ ] Measured pilot performance accepted by leadership

Documentation completion does not mean the store is staffed, trained, stocked, safe or operating.
