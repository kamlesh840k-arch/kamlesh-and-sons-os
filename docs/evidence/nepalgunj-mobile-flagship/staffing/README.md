## Governance rule

These documents are site-specific staffing evidence. They do not create employment contracts or override Nepal law, approved company policy or the canonical K&S OS. Salary bands, working hours, leave, benefits, disciplinary steps, monitoring, privacy and termination require qualified local review before use.

No candidate is hired and no role is active merely because its description exists.
